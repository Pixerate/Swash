iOS: the formatting bar above the keyboard is Liquid Glass and scrolls sideways, so no button is cut off on smaller iPhones. A new Aa button swaps the keyboard for a format panel with text styles, inline formats and block types, as in Notes. Inline formats appear directly in the edit menu instead of under Format. The "/" block menu uses glass chips. On macOS 26 the bubble menu uses Liquid Glass.
