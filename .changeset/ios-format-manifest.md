The iOS and iPadOS formatting bar, edit menu and Format menu now read their commands, labels, order, groups and shortcuts from the shared format manifest, like the Mac's Format and bubble menus. The edit menu's Format submenu offers the bubble-menu commands that apply to the selection, including headings and block formats, and the iPadOS Format menu no longer shows Mac-only commands that did nothing on iPad.
