Writing partner: its cursor now types each fix the way a person would. It selects the word, types the new one over it, then highlights what changed for a moment. Each word it changes is its own undo step, so ⌘Z takes back one correction at a time and teaches the partner only about that one. You can keep typing while it works. The playback comes from Pixerate's editor package (0.70), so Swash and the other Pixerate editors show agents' edits the same way.
