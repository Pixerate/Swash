Slack mrkdwn documents get the full editor on iPhone and iPad: Formatted mode is now Edit Text, and the formatting bar and edit-menu formatting write Slack's own syntax (`*bold*`, `_italic_`, `~strike~`, `` `code` ``, code blocks, quotes and `<url|text>` links).
