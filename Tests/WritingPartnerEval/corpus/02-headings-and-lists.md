# Field Guide to Structured Notes

Good notes mix short headings, checklists, and clear paragraphs so you can find what you need a month later. I've used plain text files for years, and I don't want a proprietary database between me and my folder of documents.

Planning the Week
=================

## Daily Habits

- Write down the three things that matter before opening messages
- Review yesterday's notes and move unfinished items forward
- Don't leave half-written drafts scattered across temporary folders
- Keep the outline open when a document grows past a few screens

## Release Checklist

1. Build the macOS target and verify that all extensions compile cleanly
2. Run the conformance suite and check that every fixture passes
3. Check the snapshot diff when changing anything in the styling pass
4. Make sure the undo stack leaves the caret where the person was typing

## Why Plain Files Endure

What happens when a cloud service shuts down or changes its terms? If your notes live in ordinary folders on disk, you don't lose a single line. I can open the same file in a terminal, search it with standard tools, or share it with a colleague who doesn't use the same editor.

I'd rather have simple files that last fifty years than a clever workspace that locks them away. Everything looks OK on both Mac and iPad, but the folder scanner still needs a quick check when a directory has thousands of nested files.
